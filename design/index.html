jubrolab 디자인 시안

5 DIRECTIONS · 각 시안은 8개 프로젝트 실제 내용으로 채워져 있습니다

01단일 컬럼 · 라이트

관찰 일지 — Field Notes

모눈 종이 위의 실험 기록. 세리프 제목에 형광펜이 지나가고, 여백에는 손글씨로 한 줄씩 적어둡니다. 읽는 사이트.
02그리드 + 프리뷰 · 다크

셀렉트 화면 — Arcade Select

게임 캐릭터 선택 화면. 타일 8개를 방향키로 옮겨 다니면 오른쪽 패널이 바뀝니다. 고르는 사이트.
03테이블 · 다크

배포 현황판 — Departure Board

공항 안내판. 이름이 스플릿플랩으로 넘어가고 램프로 운영 여부를 알립니다. 훑는 사이트.
04무한 캔버스 · 라이트

작업 캔버스 — Workspace Canvas

끌고 굴려서 보는 노드 맵. 가운데 허브에서 게임/도구로 간선이 뻗고, 노드를 누르면 패널이 열립니다. 돌아다니는 사이트.
05전시 그리드 · 다크

암실 전시 — Darkroom

각 프로젝트의 이름을 해시로 돌려 그림을 생성합니다. 미술관 벽 라벨 형식의 캡션. 보는 사이트.
